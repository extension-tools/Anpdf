Vous avez installé Écrire sur un PDF — Annotate PDF

Commencez en trois étapes.

1 Cliquez sur l’icône en forme de puzzle dans la barre d’outils du navigateur.
2 Repérez Écrire sur un PDF — Annotate PDF et cliquez sur l’épingle.

3 Cliquez sur l’icône Écrire sur un PDF — Annotate PDF, puis sur Ouvrir un PDF pour choisir votre document.
